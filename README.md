# نظام التشغيل التربوي — P3

**الحالة: P3 مكتمل، وP4 لم يبدأ.**

مشروع Next.js App Router وTypeScript لإعداد البرامج وتشغيل جلساتها وتتبع تقدم الطلاب. يدعم قوالب البرامج، الخطط والدفعات والمجموعات، وإدارة الجلسات والحضور والمعايير والتصحيح التاريخي. يضيف P3 تعريف الأوراد والعادات والقيم والأهداف، والاستحقاقات اليومية والأسبوعية، وإدخال الطالب والمربي والتفريغ الورقي، والمراجعة المرتبطة بنسخة السجل. تعمل الطلبات عبر مستخدم PostgreSQL محدود مع RLS إجباري.

الأقفال المعتمدة:

- ملخص الأسبوع تلقائي؛ لا طابور اعتماد أسبوعي إلزامي على المسؤول.
- دور واحد للحساب؛ يستطيع المسؤول تنفيذ أعمال المربي داخل الجهة، مع حفظ المنفذ الفعلي ونسبة المسؤولية التاريخية.
- الاعتماد على جلسات Supabase الأصلية تجربة قبول مطلوبة، وليس افتراضًا مثبتًا.

## التشغيل المحلي

Node.js 24، ثم:

```sh
npm ci
npm run dev:runtime
```

افتح `http://localhost:3000`. `/health` يفحص حياة التطبيق؛ `/ready` يثبت اتصال قاعدة البيانات ودور التشغيل المحدود وأحدث migration مطلوبة.

```sh
npm run format:check
npm run lint
npm run typecheck
npm test
npm run build
npm run smoke
```

اختبارات قاعدة البيانات تستخدم PGlite محليًا. لا تُعد بديلًا لاختبارات Supabase أو Vercel أو اتصالات PostgreSQL المجمعة.
