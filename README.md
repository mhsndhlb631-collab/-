# نظام التشغيل التربوي — أساس P0

**الحالة: تنفيذ محلي جزئي. P0 لم يكتمل، وP1 لم يبدأ.**

مشروع Next.js App Router وTypeScript، مع مخطط PostgreSQL تأسيسي وخدمات حسابات مختبرة. تم تطبيق المخطط على Supabase الحقيقي واجتاز مستخدم التشغيل المحدود واختبار إنشاء الهوية المعطلة وربطها وتفعيلها، وتجديد وإبطال الجلسة والدخول الجديد. لا يوجد مسار دخول عام بعد؛ ما زالت مستودعات PostgreSQL والأوامر وواجهات HTTP واختبارات الخصوصية الكاملة مطلوبة قبل فتحه.

الأقفال المعتمدة:

- ملخص الأسبوع تلقائي؛ لا طابور اعتماد أسبوعي إلزامي على المسؤول.
- دور واحد للحساب؛ يستطيع المسؤول تنفيذ أعمال المربي داخل الجهة، مع حفظ المنفذ الفعلي ونسبة المسؤولية التاريخية.
- الاعتماد على جلسات Supabase الأصلية تجربة قبول مطلوبة، وليس افتراضًا مثبتًا.

## التشغيل المحلي

Node.js 24، ثم:

```sh
npm ci
npm run dev
```

افتح `http://localhost:3000`. الصفحة الحالية غلاف تأسيسي فقط. `/health` يفحص حياة التطبيق؛ `/ready` يعيد 503 عند غياب اتصال قاعدة بيانات تشغيل آمن.

```sh
npm run format:check
npm run lint
npm run typecheck
npm test
npm run build
npm run smoke
```

اختبارات قاعدة البيانات تستخدم PGlite محليًا. لا تُعد بديلًا لاختبارات Supabase أو Vercel أو اتصالات PostgreSQL المجمعة.
